# Icons

## Fluent UI System Icons

`search.svg`, `arrow-sync.svg`, `settings.svg`, `info.svg`,
`document-arrow-right.svg`, `copy.svg`, `save.svg` and `folder-open.svg` are the
20 px *regular* variants of the corresponding icons from
[Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)
(`assets/<Name>/SVG/ic_fluent_<name>_20_regular.svg`), unmodified. They are
recoloured at runtime by `qtrequestory/ui/icons.py` to follow the system light
or dark palette; the files themselves keep the upstream `#212121` fill.

`calendar.svg`, `dismiss.svg`, `text-bullet-list-tree.svg` and `wrench.svg` are the same family's
20 px *regular* `calendar_ltr`, `dismiss`, `text_bullet_list_tree` and `wrench` glyphs, redrawn on the
same 20 px grid, under the same licence.

## Application icon

`app.svg` is original artwork for this project (a log page with three lines and
a magnifier, accent `#0F6CBD`) and is covered by the licence of the repository.
It is the only icon that is **not** tinted: its colours are part of the brand.
